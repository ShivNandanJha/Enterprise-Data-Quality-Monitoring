# GTM Icon Library

Professional SVG icon system for modern B2B GTM, Sales, Marketing, Revenue, Growth, RevOps, and Business Intelligence use cases.

## Design System

- Canvas: `24x24` (`viewBox="0 0 24 24"`)
- Internal padding: ~2–3px optical safe area
- Outline style: 2px stroke, rounded caps and joins
- Filled style: solid geometric forms derived from same concept geometry
- Color palette foundation: `#2E6FED`, `#0B1220`, `#65A4F2`, `#81CBFB`, `#B1DFFD`, `#DFF2FE`, `#F4F5F7`, `#FFFFFF`
- Accent usage (secondary only): `#FFC857` for key alerts/opportunity states

## Naming Convention

`gtm_[category]_[icon-name]_[style].svg`
